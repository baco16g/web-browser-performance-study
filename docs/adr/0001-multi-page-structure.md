# 0001 ユースケースごとに独立したページにする

## 状況

ユースケースごとに、読み込み時の性能を含めて測りたい。単一ページのアプリで画面を切り替えると、前の画面の状態やキャッシュが次の計測に混ざる。

## 決定

Vite のマルチページ構成にして、ユースケースごとに HTML の入口を分ける。

## 理由

ページ遷移のたびに実行環境が作り直されるので、計測の前提がそろう。各ページが読み込むのは必要なコードだけになる。HTML を直接書けるので、UC4 で `preload` や `defer` の違いも試せる。

## 選ばなかった案

- **単一ページのアプリ:** 共通部品の再利用は楽だが、画面間で状態が残る。読み込み性能の教材にも向かない。
- **ユースケースごとの別パッケージ:** 分離は最も強いが、設定の重複が増える。学習の主題から外れる。
