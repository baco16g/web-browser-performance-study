# 0003 回帰の判定に相対、絶対、揺れの3条件を使う

## 状況

計測値は実行のたびに揺れる。わずかな差で失敗にすると判定が信用されなくなり、基準を甘くすると実際の悪化を見逃す。

## 決定

中央値の悪化が、割合のしきい値、量のしきい値、四分位範囲のすべてを超えたときに `fail` とする。しきい値の半分を超えた場合は `warn` とする。しきい値は指標の単位ごとに `bench/compare.ts` で定める。

## 理由

割合は値の小さい指標での誤検知を防ぎ、量は意味のない微小な差を除く。四分位範囲は、その実行の揺れに判定を合わせる。どれも結果の JSON から計算でき、判定の理由を数値で説明できる。

## 選ばなかった案

- **マン・ホイットニーの U 検定やブートストラップ:** 統計的には正確だが、読み込み 5 回の規模では検出力が低い。実装と説明の費用に見合わないと判断した。回数を増やすときに見直す。
- **固定の予算値だけを使う:** 分かりやすいが、緩やかな悪化を検知できない。予算は別の仕組みとして追加する。
